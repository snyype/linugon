Features

Everything a local PHP stack needs

No Docker, no YAML, nothing to keep running in a terminal tab. Native packages, managed for you.

Automatic virtual hosts

Every folder in www/ becomes <folder>.test. Delete the folder and the site disappears.

Custom domains

Point api.shop.local at any folder on disk. Custom hosts are never touched by auto-sync.

Friendly terminal UI

Menus and checklists, live spinners and timings, with plain prompts when whiptail isn't installed.

Quick or solo installs

Install the full stack in one go, or tick just Redis, or just Node. Dependencies are resolved for you.

Multiple PHP versions

Install PHP 5.6–8.x side by side (ondrej PPA on Ubuntu) and switch CLI + Apache with linugon php 8.3.

MySQL + phpMyAdmin

Installed non-interactively, plus an optional password-based admin user so phpMyAdmin and Laravel can log in.

localhost dashboard

Open http://localhost for every site in a grid, with phpMyAdmin and phpinfo() one click away.

Clean /etc/hosts

All entries live in one managed block. No duplicates, and stale lines are cleaned up when sites are removed.

Permissions that just work

Apache runs as you, so projects in $HOME load and storage/ is writable without chmod 777.

How auto virtual hosts work

From mkdir to browser in seconds

A small systemd watcher keeps Apache and /etc/hosts in step with your projects folder. Nothing to restart, nothing to click.

Get started

Up and running in three steps

Requires Debian or Ubuntu with systemd, and a normal user with sudo. Don't run it as root.

  1. Install the linugon command

    Downloads the script to /usr/local/bin/linugon, which is already on your PATH.

    $ curl -fsSL "https://raw.githubusercontent.com/snyype/linugon/master/install.sh?v=$(date +%s)" | bash

    No curl? wget -qO- "https://raw.githubusercontent.com/snyype/linugon/master/install.sh?v=$(date +%s)" | bash

  2. Set up your stack

    Choose Quick install, or Install components to pick.

    linugon

  3. Create a project

    Then open http://hello.test. Update Linugon any time with linugon self-update.

    mkdir ~/linugon-linux/www/hello
echo '<?php phpinfo();' > ~/linugon-linux/www/hello/index.php
Command line

Scriptable when you want it

Everything in the menu is also a subcommand.

linugonOpen the interactive menu
linugon install allApache, PHP, MySQL, phpMyAdmin, Composer
linugon install redis nodeSolo install: only the components you name
linugon vhost add myapphttp://myapp.test → ~/linugon-linux/www/myapp
linugon vhost add api.shop.local ~/code/shop/publicCustom domain pointing at any folder
linugon vhost remove api.shop.localRemove a site (project files are kept)
linugon vhost listList every site with its type and document root
linugon syncMatch vhosts to the folders in www/ right now
linugon watch on|offToggle automatic virtual hosts
linugon php 8.3Switch PHP for the CLI and Apache
linugon statusVersions, services and vhost count at a glance
linugon self-updateDownload the latest Linugon to /usr/local/bin
FAQ

Questions

Which distros are supported?

Debian and Ubuntu (anything apt-based with systemd). On Ubuntu, Linugon can add the ondrej/php PPA for extra PHP versions. On Debian you get the distro's PHP.

Why can't I log in to phpMyAdmin as root?

MySQL's root uses socket authentication, so it only works through sudo mysql. The installer offers to create a password-based admin user. Use that one for phpMyAdmin and your .env files.

Will it touch my existing Apache sites?

No. Linugon only manages files named linugon-*.conf and its own block in /etc/hosts. The only exception is vhosts made by Linugon v1, which are migrated automatically.

How do I stop a folder from getting a site?

Rename it to start with _ (for example _backup), or turn automatic vhosts off with linugon watch off.

Where are the logs?

Each site's Apache access and error logs, plus the installer's full output (linugon.log), are in ~/linugon-linux/logs/.

Does it support HTTPS or Nginx?

Not yet. Linugon currently targets Apache over HTTP. Contributions are welcome.
